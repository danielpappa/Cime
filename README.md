## Overview

Inspired by the Three Peaks in the Dolomites, **cime** combines daily goal-setting with peer accountability. Users set three daily targets ("summits") - such as completing a workout, finishing a coding sprint, or reading a chapter.

To eliminate endless scrolling, access to the social feed is earned: completing a summit unlocks a view of a friend's latest achievement. To promote consistent daily action and prevent clutter, all summits reset automatically at midnight, giving everyone a fresh start every day.

## Key Views and Features

- **Climb View:** Set three daily peaks to conquer and upload proof upon completion.
- **Friend Feed:** Check out what your friends achieved today, get inspired, react and comment.
- **Discover:** Discover the best summits matching your interests/habits in order to find some inspiration and be able to set more ambitious goals in the future.
- **Settings:** Morning reminders, privacy levels, hard reset etc.
- **Widget:** A basic overview of today's climbing progress.
